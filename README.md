# NodeCloak documentation

Public, user-facing guides for NodeCloak. The site is published with GitHub Pages at
<https://nodecloak.github.io/nodecloak-docs/> and linked from <https://nodecloak.com/>.

The guides cover browser profiles, proxies and fingerprint settings, encrypted sync,
sharing, terminal workspaces, troubleshooting, and MCP connections.
NodeCloak 3.0.0 supports local stdio and remote HTTPS MCP connections. The guides cover
desktop authorization, profile and website permissions, page tools, and sync previews.

## Contributing

The site is plain HTML, CSS, SVG and JavaScript. Open `index.html` locally to review it.
Keep instructions grounded in released product behavior, and do not include credentials,
account data, private deployment details, or test screenshots containing local secrets.

Documentation text and original diagrams use CC BY 4.0. Product logos and screenshots
remain NodeCloak property. See `LICENSE`.
